---
name: 분석 DB 직원 권한
description: DB 단위·행 단위 배정과 관리자 전용 DB 메모의 권한 경계를 설명한다.
---

직원에게 DB 단위로 배정하면 해당 DB의 데이터 행을 열람하고 행별 메모를 사용할 수 있다. 행 단위로만 배정하면 상위 DB가 분석 DB 목록에 나타나고 본인에게 배정된 행만 볼 수 있다. DB 전체 메모는 owner만 조회하고 작성한다.

**Why:** DB 배정 후 직원 화면에 데이터가 표시되어야 하지만, DB 전체 메모는 직원에게 노출하지 말아야 한다는 운영 요구가 확인됐다.

**How to apply:** DB 목록은 DB 담당 또는 하위 행 담당 여부를 모두 확인한다. 행 조회·행별 메모 권한과 DB 전체 메모 권한을 분리하고, DB 전체 메모 UI와 API는 owner 전용으로 강제한다.
