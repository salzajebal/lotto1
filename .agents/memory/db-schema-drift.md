---
name: DB 스키마 드리프트
description: 개발 DB 스키마 반영 시 기존 관리자 데이터 삭제 위험을 피하기 위한 원칙
---

자동 스키마 push가 기존 관리자 아이디 고유 제약조건을 다시 만들면서 관리자 테이블 비우기를 제안하면 강제 진행하지 않는다.

**Why:** 현재 개발 DB와 선언 스키마 사이의 제약조건 차이 때문에, 관계없는 회원 컬럼 추가에도 관리자 데이터 삭제를 요구하는 대화형 경고가 발생할 수 있다.

**How to apply:** 변경 범위를 먼저 확인하고 기존 데이터 보존이 필요한 경우 필요한 컬럼·제약조건만 대상으로 안전한 비파괴 변경을 적용한 뒤 실제 스키마를 조회해 검증한다.
