---
name: 캔버스 라이브 전환
description: 목업 iframe의 building 상태를 live로 전환할 때 적용할 안전한 작업 순서
---

목업 iframe을 `building`에서 `live`로 바꿀 때 URL·컴포넌트 정보·후속 제안을 먼저 업데이트하고, 정렬이나 분배는 별도 캔버스 작업으로 실행한다.

**Why:** 라이브 전환 업데이트와 여러 레이아웃 작업을 하나의 원자적 배치에 섞으면 전체 배치가 초기 검증에서 실패해 어느 shape도 갱신되지 않을 수 있다.

**How to apply:** 기존 placeholder를 완성된 목업으로 연결할 때 각 iframe 업데이트 성공을 먼저 확인한 뒤, 필요한 경우에만 다음 호출에서 정렬·분배한다.
